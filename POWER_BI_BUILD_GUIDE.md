# Power BI Build Guide

A native `.pbix` file is not generated by this starter pack. Build the report in Power BI Desktop using the supplied CSV files.

## Load data
1. Open Power BI Desktop.
2. Select **Get data > Text/CSV**.
3. Load `data/inventory_snapshot.csv`.
4. Load `data/physical_count.csv` as a second table.
5. Set date, whole-number and decimal data types correctly.

## Suggested report pages
### Page 1: Executive Inventory Overview
- KPI cards: On-hand units, available units, inventory value, SKU count.
- Bar chart: Inventory value by warehouse.
- Column chart: Inventory value by category.
- Table: Reorder exceptions.

### Page 2: Inventory Risk
- Ageing band by inventory value.
- Top 10 SKUs by days since last movement.
- Excess quantity and excess value by warehouse.

### Page 3: Stock Accuracy
- System quantity versus physical count.
- Absolute variance by warehouse.
- SKU-level variance table.

## Suggested DAX measures
```DAX
On Hand Units = SUM(inventory_snapshot[on_hand_qty])

Available Units = SUM(inventory_snapshot[available_qty])

Inventory Value =
SUMX(inventory_snapshot,
    inventory_snapshot[on_hand_qty] * inventory_snapshot[unit_cost])

Reorder Exceptions =
COUNTROWS(
    FILTER(inventory_snapshot,
        inventory_snapshot[available_qty] <= inventory_snapshot[reorder_point]
    )
)

Excess Stock Value =
SUMX(inventory_snapshot,
    MAX(0, inventory_snapshot[on_hand_qty] - inventory_snapshot[target_stock_qty])
    * inventory_snapshot[unit_cost]
)
```

Use descriptive titles, clear units, visible filters and a note that the dataset is synthetic. Save the report as `Inventory_Intelligence_Dashboard.pbix` in this folder.
