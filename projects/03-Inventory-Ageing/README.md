# Project 03: Inventory Ageing and Dead-Stock Analysis

## Project Objective
Analyse inventory ageing patterns to identify slow-moving, non-moving and potentially obsolete stock, quantify financial exposure and recommend corrective actions.

## Business Questions
1. Which inventory items have remained unused for the longest period?
2. What percentage of inventory is ageing beyond 90, 180 and 365 days?
3. Which warehouses hold the highest value of ageing inventory?
4. How much working capital is tied up in slow-moving and obsolete stock?
5. What actions can management take to reduce inventory losses?

## Analytical Techniques
- Inventory Ageing Analysis
- Slow-Moving Stock Identification
- Non-Moving Stock Analysis
- Obsolete Inventory Identification
- Inventory Value Exposure Analysis

## Tools
- Microsoft Excel
- SQL
- Power BI

## Key Performance Indicators
- Inventory Ageing Ratio
- Slow-Moving Stock Value
- Non-Moving Stock Value
- Obsolete Inventory Value
- Percentage of Stock Above 180 Days
- Working Capital Tied Up in Ageing Stock

## Deliverables
- Inventory ageing dataset
- Excel ageing analysis and dashboard
- SQL analytical queries
- Power BI inventory ageing dashboard
- Management report and recommendations

## Expected Business Value
Improve inventory utilisation, reduce obsolete stock exposure, release working capital and strengthen inventory planning.

**Data:** Synthetic demonstration dataset.
