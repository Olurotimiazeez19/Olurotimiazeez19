# Project 04: Stock Accuracy and Inventory Reconciliation

## Project Objective
Evaluate inventory record accuracy by comparing ERP system balances with physical stock counts, identifying discrepancies, and recommending inventory-control improvements.

## Business Questions
1. How accurately does the ERP reflect physical inventory?
2. Which warehouses have the highest stock discrepancies?
3. Which SKUs experience frequent inventory variances?
4. What is the financial value of inventory discrepancies?
5. What operational weaknesses contribute to stock inaccuracies?

## Analytical Techniques
- Physical Stock Reconciliation
- Inventory Variance Analysis
- Root Cause Analysis
- Cycle Counting
- Inventory Control Assessment

## Tools
- Microsoft Excel
- SQL
- Power BI

## Key Performance Indicators
- Inventory Record Accuracy (%)
- Stock Variance Quantity
- Stock Variance Value
- Number of Discrepant SKUs
- Warehouse Stock Accuracy
- Reconciliation Completion Rate

## Deliverables
- Physical versus system stock dataset
- Excel reconciliation workbook
- SQL reconciliation queries
- Power BI stock accuracy dashboard
- Inventory discrepancy report
- Management recommendations

## Expected Business Value
Improve inventory record accuracy, strengthen warehouse controls, reduce stock losses and support reliable procurement and operational planning.

**Data:** Synthetic demonstration dataset.
