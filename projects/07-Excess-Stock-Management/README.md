# Project 07: Excess Stock and Overstock Management

## Project Objective
Identify excess inventory across warehouse locations, analyse overstock situations, quantify financial exposure and develop strategies to optimise stock levels and reduce unnecessary working capital investment.

## Business Questions
1. Which inventory items have quantities above their approved stock targets?
2. Which warehouses hold the highest levels of excess inventory?
3. What is the financial value of excess and overstocked items?
4. What factors contribute to persistent overstock situations?
5. How can excess inventory be reduced without disrupting operational activities?

## Analytical Techniques
- Excess Stock Identification
- Overstock Analysis
- Safety Stock Assessment
- Reorder Level Analysis
- Inventory Optimisation
- Working Capital Exposure Analysis

## Tools
- Microsoft Excel
- SQL
- Power BI

## Key Performance Indicators
- Total Excess Stock Quantity
- Excess Inventory Value
- Overstock Percentage
- Excess Stock by Warehouse
- Excess Stock by Category
- Stock Above Target Level
- Potential Working Capital Release

## Deliverables
- Excess inventory dataset
- Excel overstock analysis model
- SQL analytical queries
- Power BI excess stock dashboard
- Inventory optimisation report
- Management recommendations

## Expected Business Value
Reduce unnecessary inventory investment, improve warehouse utilisation, release working capital, minimise storage costs and strengthen inventory replenishment decisions.

**Data:** Synthetic demonstration dataset.
