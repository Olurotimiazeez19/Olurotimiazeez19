# Project 06: Inventory Valuation and Capital Exposure Analysis

## Project Objective
Analyse inventory value across warehouse locations, product categories and stock classifications to determine financial exposure, identify capital tied up in inventory and support better working capital decisions.

## Business Questions
1. What is the total financial value of inventory held across all warehouses?
2. Which product categories account for the highest inventory value?
3. Which warehouses hold the largest proportion of working capital?
4. How much capital is tied up in slow-moving and excess inventory?
5. How can inventory investment be optimised without compromising operational availability?

## Analytical Techniques
- Inventory Valuation Analysis
- Weighted Average Cost Analysis
- Stock Value Segmentation
- Working Capital Analysis
- Excess Inventory Valuation
- Financial Exposure Assessment

## Tools
- Microsoft Excel
- SQL
- Power BI

## Key Performance Indicators
- Total Inventory Value
- Average Inventory Value
- Inventory Value by Warehouse
- Inventory Value by Category
- Excess Stock Financial Exposure
- Slow-Moving Inventory Value
- Working Capital Tied Up in Inventory

## Deliverables
- Inventory valuation dataset
- Excel inventory valuation model
- SQL financial analysis queries
- Power BI inventory valuation dashboard
- Working capital analysis report
- Management recommendations

## Expected Business Value
Improve inventory investment decisions, increase working capital visibility, reduce unnecessary capital exposure and support financially sustainable inventory management.

**Data:** Synthetic demonstration dataset.
