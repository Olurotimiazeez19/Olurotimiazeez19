# Project 02: ABC/XYZ Inventory Classification

## Project Objective
Develop an inventory classification model that prioritises stock based on annual consumption value and demand variability.

## Business Questions
1. Which items contribute the most to annual inventory consumption value?
2. Which products have stable or unpredictable demand?
3. Which inventory items require closer management attention?
4. How should purchasing policies differ across inventory classes?

## Analytical Techniques
- ABC Classification
- XYZ Classification
- Annual Consumption Value
- Demand Variability Analysis
- Inventory Segmentation

## Tools
- Microsoft Excel
- SQL
- Power BI

## Key Performance Indicators
- Annual Consumption Value
- ABC Classification
- Demand Variability
- SKU Distribution by Class
- Inventory Value by Class

## Deliverables
- Cleaned inventory dataset
- Excel classification model
- SQL analytical queries
- Power BI dashboard
- Management recommendations

**Data:** Synthetic demonstration dataset.
