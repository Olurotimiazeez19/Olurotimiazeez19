# Project 05: Inventory Turnover and Stock Performance Analysis

## Project Objective
Evaluate inventory movement and utilisation efficiency by analysing inventory turnover, consumption patterns and stock holding periods.

## Business Questions
1. Which inventory items have the highest and lowest turnover?
2. Which products are consuming warehouse storage capacity without sufficient movement?
3. How efficiently is inventory being converted into operational consumption?
4. Which categories require improved replenishment planning?
5. How can inventory holding costs be reduced without increasing stockout risks?

## Analytical Techniques
- Inventory Turnover Analysis
- Average Inventory Calculation
- Consumption Trend Analysis
- Days Inventory Outstanding (DIO)
- Stock Movement Analysis
- Replenishment Performance Analysis

## Tools
- Microsoft Excel
- SQL
- Power BI

## Key Performance Indicators
- Inventory Turnover Ratio
- Days Inventory Outstanding
- Average Inventory Value
- Annual Consumption Value
- Stock Movement Rate
- Slow-Moving Inventory Percentage

## Deliverables
- Inventory movement dataset
- Excel inventory turnover model
- SQL analytical queries
- Power BI inventory performance dashboard
- Management performance report
- Recommendations for inventory optimisation

## Expected Business Value
Improve inventory utilisation, reduce unnecessary stock holding, optimise working capital and support more effective replenishment decisions.

**Data:** Synthetic demonstration dataset.
